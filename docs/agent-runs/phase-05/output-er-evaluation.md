## 3. Counting rules

- Only MATCH and NON_MATCH labels are counted, 241 rows in all. UNSURE (39 rows) is reported separately, in section 6.
- TP = MATCH accepted. FP = NON_MATCH accepted. TN = NON_MATCH rejected. FN = MATCH rejected.
- UNRESOLVED and CONFLICT are not definite decisions. They are outside TP, FP, TN and FN, and they lower **coverage** = (TP+FP+TN+FN) / labeled.
- **Precision** = TP / (TP+FP).
- **Recall** = TP / all MATCH labels. A MATCH left UNRESOLVED or CONFLICT therefore counts against recall.
- **Recall (decided)** = TP / (TP+FN) is also given.
- F1 uses precision and recall.
- **Unresolved rate** = UNRESOLVED / labeled. It is also given over the whole run.
- Confidence intervals are Wilson 95% score intervals (z = 1.95996).
