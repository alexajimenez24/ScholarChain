# Dataset schemas and normalization notes

Owner: dataset-engineer. These notes describe the shape of each source as observed in the committed
samples (`datasets/samples/real/`, retrieved 2026-11-22) and map it onto the shared contracts that
domain-engineer defines in `modules/core` (WorkRecord, AuthorMention and related records).
The mapping column states intent; the parsers belong to hadoop-engineer and the match policy to
entity-resolution-engineer. Field names below are source field names, not core field names.

## DBLP XML (`dblp.dtd`)

Observed on 2026-11-22: the dump declares `encoding="ISO-8859-1"` and `<!DOCTYPE dblp SYSTEM "dblp.dtd">`.
Parsers must honor the declared encoding and resolve the character entities (`&uuml;` and so on) from the DTD.
The DTD is committed at `datasets/samples/real/dblp.dtd` (13134 bytes, CC0 header, fetched by `fetch_samples.py dtd`);
point the parser's external-subset resolver at it, because `xml.etree` alone fails on the entities
(`tests/module-unit/datasets` shows a working expat setup for both DBLP sample files).
A record is one top-level child of `<dblp>`; mixed-content `<title>` may contain inline markup (`<i>`, `<sub>`).

| DBLP element or attribute | Meaning and mapping intent | Notes |
|---|---|---|
| record element name | record type | retained: article, inproceedings, incollection, book, phdthesis, mastersthesis; skipped and counted: www, proceedings, data |
| `@key` | DBLP key, the authoritative work source ID | for example `reference/vision/SrivastavaPKTA14` |
| `@mdate` | last modification date of the record | |
| `title` | work title | trailing period is part of the DBLP text |
| `author` (ordered, repeated) | author sequence; position is the document order | a numeric suffix such as `Gaurav Srivastava 0004` is a DBLP homonym disambiguator |
| `author/@orcid` | ORCID iD asserted by DBLP | present on 3 author elements of the committed sample; self-reported |
| `year` | publication year | |
| `journal`, `booktitle`, `school`, `publisher` | venue-like fields | first present wins; venue stream is the key prefix |
| `pages`, `volume`, `number` | bibliographic detail | not needed for linkage |
| `ee` (repeated) | electronic edition URLs | a `https://doi.org/10.xxxx/...` value is the DOI link; others are plain URLs |
| `url` | DBLP-relative page | |

## OpenAlex Work (JSONL, projected)

Projection requested by the script: `select=id,doi,display_name,publication_year,type,authorships,topics,primary_location`.

- `id`: OpenAlex work URL (`https://openalex.org/W...`); `doi`: DOI as URL; `display_name`: title;
  `publication_year`; `type`.
- `authorships[]`: `author_position`, `author.{id,display_name,orcid}`, `raw_author_name`,
  `institutions[].{id,display_name,ror,country_code}`.
- `topics[]`: `id`, `display_name`, with `subfield`, `field`, `domain` and a `score`.
- `primary_location.source`: `id`, `display_name`, `issn_l`, `type`.

## Crossref work (JSONL, projected)

Kept fields: `DOI`, `title[]`, `author[].{given,family,name,sequence,ORCID,affiliation[]}`,
`issued.date-parts`, `container-title[]`, `type`, `publisher`. Dropped on purpose: `abstract`
(possible publisher copyright) and `reference` (large, not needed for coauthorship). DOIs are
case-insensitive; compare lower-cased.

## ORCID record (API v3.0, local only)

`orcid-identifier.path`, `person.name.{given-names,family-name,credit-name}.value`,
`person.other-names.other-name[].content`, `activities-summary.employments`, and
`activities-summary.works.group[].external-ids` with type `doi`. Real records are personal data and
are never committed; the synthetic fixture holds a reduced record with the same paths.

## Linkage keys

Evidence order follows the specification: DOI, ORCID, OpenAlex ID first; normalized title, year and
author sequence next. Normalization is the job of the Hadoop normalizers, not of these notes.

## Synthetic fixtures

`datasets/samples/fixtures/` is generated by `datasets/scripts/make-fixtures.py`: invented people,
titles and DOIs under the Crossref test prefix 10.5555, in a small coauthorship graph whose metrics can
be computed by hand (two communities, a bridge researcher, a second component, a singleton, a 12-author
paper, and two homonyms `Wei Wang 0001` and `Wei Wang 0002`). It is not real data and must never be
presented as a result.
